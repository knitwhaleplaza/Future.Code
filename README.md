# Book Tracker — трекер прочитанных книг

**Автор:** Варлашкина Елизавета Дмитриевна
**Дата** Апрель 2026

## Описание программы

Book Tracker — это десктопное приложение на Python с графическим интерфейсом для учёта прочитанных книг. Позволяет добавлять книги, удалять, фильтровать по жанру и количеству страниц, а также сохранять/загружать данные в формате JSON.

## Функциональные возможности

- Добавление книги с указанием названия, автора, жанра и количества страниц
- Валидация данных: поля не могут быть пустыми, страницы — только положительное число
- Отображение списка книг в таблице
- Фильтрация:
  - По жанру (выпадающий список)
  - По количеству страниц (книги с числом страниц больше заданного)
- Удаление выбранной книги
- Сохранение всех данных в JSON-файл
- Автоматическая загрузка данных при запуске

## Технологии

- Python 3.x
- Tkinter (встроенная библиотека)
- JSON для хранения данных

## Установка и запуск

1. Убедитесь, что установлен Python 3 (https://python.org)
2. Скачайте файл `book_tracker.py`
3. Запустите через терминал:

```bash
python book_tracker.py
